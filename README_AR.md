# Féminine Mind — Platform V3

هذه النسخة هي **واجهة Web App مجانية أولية قابلة للنشر** مع بنية واضحة للتوسع.

## الموجود الآن
- واجهة عربية RTL متجاوبة.
- محادثة توعوية تجريبية بأسلوب Feminine Mind.
- مقالات أسبوعية نموذجية.
- توكيدات صباحية.
- تمرين وسلوك يومي.
- اختبارات تأملية مجانية + بطاقات Premium.
- لوحة Admin محلية لإضافة المقالات والتوكيدات.
- PWA: manifest + service worker.
- مساحة Banner للإعلانات/التسويق بالعمولة.
- بنية Free/Premium جاهزة.

## ما يحتاج ربطاً خارجياً قبل أن يصبح تلقائياً على الإنترنت
1. Backend وقاعدة بيانات.
2. نظام تسجيل دخول آمن للمستخدمات وAdmin.
3. مزود AI حقيقي ومفتاح API محفوظ على الخادم، وليس داخل JavaScript.
4. Scheduler/Cron لتشغيل إنتاج المحتوى يومياً وأسبوعياً.
5. نظام دفع إذا قررتِ إطلاق Premium.
6. خدمة حجز للجلسات عند إطلاقها.

## النشر المجاني
ارفعي هذه الملفات إلى أي استضافة Static تدعم HTTPS. بعد النشر يصبح لديك رابط عام يمكن وضعه في Instagram وFacebook.

لأفضل تجربة PWA، يجب أن يكون الموقع عبر HTTPS أو localhost.

## مهم
المحادثة الموجودة في هذه النسخة ليست اتصالاً حقيقياً بنموذج AI خارجي؛ هي طبقة تجريبية محلية. هذا مقصود حتى لا تضعي مفتاح API داخل المتصفح.

## قواعد المحتوى
- لا يوجد تشخيص آلي.
- لا تُعرض الاختبارات على أنها تشخيص سريري.
- عند وجود مؤشرات خطر أو إساءة، يجب توجيه المستخدمة لطلب مساعدة مهنية/طارئة مناسبة.
- يجب مراجعة المحتوى النفسي المولّد آلياً وفق سياسة Feminine Mind قبل النشر الآلي النهائي.

## الحساب الإداري
admin.html يحتوي على دخول تجريبي محلي فقط. لا تستخدميه لحماية منصة عامة. عند النشر الحقيقي يجب استبداله بنظام مصادقة خادمي آمن.
